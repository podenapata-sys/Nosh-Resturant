# NOSH Dhanmondi — Website Preview

Single-page, mobile-first website preview for NOSH Dhanmondi (Pan-Asian & Japanese restaurant, Road 2, Dhanmondi, Dhaka).

- English / Bangla toggle (add `?lang=bn` to the URL to open in Bangla)
- Animated hero, signature dishes, tabbed menu, ambience, reviews, visit info
- Call and WhatsApp buttons

Built by FutureStack Solutions. Photos are demo placeholders, to be replaced with the restaurant's own photos.
